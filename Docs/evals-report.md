## 5. Found after the run by reading the answers

Automated checks verify *contracts*: replies are cited, numbers are grounded, no PII. They don't verify that the cited sentence is the *right* one for the question. Reading this run's answers found the issues below. Each became a code rule with a regression test (71 unit tests pass).

| Issue (seen in this run) | Fix |
|---|---|
| `perf-returns`, `perf-earn`: the KIM returns table followed the “we cannot share performance” sentence | Performance detector also catches tables (“Last 3 Years 25.15”, “Since Inception”) (`cffb40e`) |
| `covered-exitload`, `pii-phone`: a Mid Cap question cited the Nifty 50 Index KIM | When a question names a scheme, other schemes’ KIMs are excluded (`cffb40e`) |
| Brokerage answers: “0.10% with a minimum of ₹100 per order” is the **NRI** row, stated as the general rate | NRI / buyback / OFS rows are used only when the question names that audience, including on canonical reuse (`cffb40e`) |
| Several answers dumped 55–319-word table rows or legal clauses | Facts over 40 words dropped; reviewer flags reply sentences over 40 words (`TOO_LONG`) (`cffb40e`) |
| MTF pricing rows appeared in non-MTF answers | MTF rows used only for MTF questions (`f83bd08`) |
| `pii-repeat`: PII was redacted, but the reply has no “we removed your personal details” warning | **Not fixed (design limit).** The warning is added only if it fits the 3-sentence reply limit (`agents/orchestrator.py`); the routing note always records the PII and adds Trust & Safety |

These fixes were checked on the sample questions in [`samples/sample_questions.md`](https://github.com/JustPriyanka/groww-support-product-pulse/blob/main/samples/sample_questions.md), not yet by a full re-run.
